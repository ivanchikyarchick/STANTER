# STANTER — запуск і користування

## Локальний запуск

Потрібен Python 3.10 або новіший. У терміналі виконайте:

```bash
cd /Users/devvan/Downloads/stanter_backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
SECRET_KEY="замініть-на-довгий-випадковий-рядок" python app.py
```

Відкрийте `http://localhost:5055`. Не відкривайте `index.html` подвійним кліком: у такому режимі акаунти й синхронізація недоступні.

### Тестова версія без Telegram

Запустіть сервер із тестовим режимом:

```bash
cd /Users/devvan/Downloads/stanter_backend
source .venv/bin/activate
TEST_MODE=1 SECRET_KEY="локальний-тестовий-ключ" python app.py
```

Відкрийте `http://localhost:5055`, перейдіть у **Акаунт** і натисніть **Увійти як тестовий райдер**. Реєстрація в Telegram не потрібна. За бажанням ім’я тестового профілю можна змінити змінними `TEST_USER_NAME` і `TEST_USER_USERNAME`.

Не встановлюйте `TEST_MODE=1` на публічному сервері. Коли змінної немає, тестова кнопка прихована, а тестовий API повертає `404`.

## Підключення Telegram Mini App

1. Створіть бота через `@BotFather` командою `/newbot` і збережіть токен.
2. Опублікуйте сайт за HTTPS. Telegram не відкриває Mini App з HTTP-адреси.
3. У `@BotFather`: `/mybots` → ваш бот → **Bot Settings** → **Configure Mini App**, вкажіть HTTPS-адресу.
4. Запустіть вебсервер і бота в окремих процесах:

```bash
export TELEGRAM_BOT_TOKEN="токен-від-BotFather"
export PUBLIC_URL="https://ваш-домен.example"
export SECRET_KEY="довгий-випадковий-рядок"
gunicorn app:app
python bot.py
```

Бот автоматично налаштує кнопку меню **Відкрити STANTER**. Після `/start` він також надішле кнопку запуску застосунку. Telegram-акаунт створюється лише після серверної перевірки підпису `initData`; дані старші за 24 години відхиляються.

Для перевірки GPS і датчиків на телефоні сайт потрібно відкрити через HTTPS. Для публічного розміщення запускайте `gunicorn app:app`; задайте змінну середовища `SECRET_KEY`.

## Як користуватися

1. Відкрийте застосунок кнопкою в Telegram-боті — профіль створиться автоматично.
2. За бажанням увімкніть **Показувати статистику та Telegram-профіль спільноті**. За замовчуванням усе приватне.
3. На вкладці **Трекер** закріпіть телефон, натисніть **Калібрувати** й не рухайте його 5 секунд.
4. Увімкніть **Запис станту** та дозвольте браузеру геолокацію і датчики руху.
5. Коли нахил перевищить поріг, запис почнеться автоматично; після повернення у звичайне положення — завершиться.
6. Вкладка **Архів** показує локальні записи й відтворює нахил. Авторизовані записи паралельно надсилаються на сервер.
7. В **Акаунті** видно власні підсумки, серію активних днів, досягнення та рейтинг інших користувачів із посиланнями на їхні Telegram-профілі.

База створюється автоматично у файлі `stanter.db`. Робіть резервні копії цього файла. Для масштабного продакшену рекомендовано замінити SQLite на PostgreSQL.
